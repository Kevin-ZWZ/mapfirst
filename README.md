# 邵艾伦 × 孙宇晨｜孙学、薄肌、黄毛理论：20–30 岁行动与就业指南

![MapFirst 项目封面](assets/cover.svg)

[English](README_EN.md) · 中文

> 从邵艾伦 × 孙宇晨访谈出发，把三套认知变成可执行的职业探索指南：**看岗位 → 做作品 → 要反馈 → 更新方向**。

MapFirst 面向 20–30 岁正在求职、转行或寻找长期方向的年轻人。它把“孙学”的认知更新、“薄肌”的主动身体管理和“黄毛理论”的独立执行，转译成一套有证据、有行动、有复盘的职业探索流程。

**[在线体验](https://kevin-zwz.github.io/mapfirst/)** · **[方法手册](docs/method.md)** · **[贡献指南](CONTRIBUTING.md)** · **[原视频](https://youtu.be/0Z-vhBvBmUY)**

**十秒介绍：** 看真实岗位、做七天实验、留下作品与反馈；用孙学 × 薄肌 × 黄毛理论，找到适合自己的下一步。

## 三套认知，三种动作

| 概念 | 本项目的实践化解读 | 本周能做的事 |
| --- | --- | --- |
| 孙学 | 用 AI 和一手信息扩展认知地图，保持机动性 | 收集 10 个岗位，归纳技能要求，访谈从业者 |
| 薄肌 | 主动管理身体，维持长期探索的精力 | 安排可持续的活动与休息，记录自己的状态 |
| 黄毛理论 | 减少外界评价带来的犹豫，用反馈校正行动 | 公开一份作品，向 3 位相关人士要具体意见 |

这张表是项目作者的应用框架，**不是访谈嘉宾对概念的逐字定义**。

## 20–30 岁职业路线

- **20–23 岁：探索。** 比较 2–3 个方向，阅读岗位要求，完成第一份可展示作品。
- **24–26 岁：验证。** 围绕一个可迁移技能交付作品、投递和面试，用真实反馈调整。
- **27–30 岁：积累。** 识别带来收入与选择权的能力，决定深耕、转向或建立第二曲线。

年龄是参考；实际顺序应按现金流、责任和已有能力调整。

## 30 秒开始

1. 打开[在线版本](https://kevin-zwz.github.io/mapfirst/)，或直接打开下载后的 `index.html`。
2. 写下一个具体的、有时间边界的职业问题。
3. 填写选项、信息缺口、关键假设和七天实验。
4. 行动后补上事实和下一轮调整。

所有填写内容只保存在浏览器 `localStorage`。可以导出 JSON 备份或迁移；项目没有账户、追踪脚本和后端。

## 为什么做这个项目

“认知”很容易变成收藏观点，却没有改变行动。MapFirst 把它定义为一个可观察的循环：

| 阶段 | 要回答的问题 | 产出 |
| --- | --- | --- |
| 探图 | 有哪些选项？哪些事实还不知道？ | 选项与信息缺口 |
| 小步试验 | 哪个假设最关键？如何低成本验证？ | 七天行动 |
| 复盘 | 预期和事实有什么差异？ | 证据记录 |
| 更新 | 应继续、转向还是停止？ | 下一轮选择 |

AI 在其中是**研究助手**：帮助列选项、找反例、制定验证计划。工具内置可复制的提问模板，并要求 AI 标明推测，避免把生成内容当成事实。

## 功能

- 🗺️ 六格决策画布，记录从探图到更新的一整轮思考
- ✳️ 七天小实验，迫使大问题落到近期行动
- 🤖 一键生成 AI 研究提问模板
- 💾 浏览器本地自动保存、JSON 导入与导出
- 🌱 零依赖静态页面，可直接托管在 GitHub Pages
- ♿ 响应式布局、键盘焦点样式和表单标签

## 部署到 GitHub Pages

1. 新建公开仓库，例如 `mapfirst`，上传本项目全部文件。
2. 进入仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
4. 等待部署完成，访问 `https://<用户名>.github.io/mapfirst/`。

页面可直接运行，不需要 Node.js、构建步骤或密钥。若仓库名称不同，URL 中也使用对应名称。

## 来源与边界

这个项目受[邵艾伦与孙宇晨的访谈](https://youtu.be/0Z-vhBvBmUY)启发，尤其是孙学、薄肌、黄毛理论与“探图”相关讨论。MapFirst 对这些概念的职业应用是独立整理和实现，**并非访谈嘉宾参与或认可的官方项目**。项目不复刻视频字幕或逐字稿。

对于医疗、法律、投资等高风险决定，画布只能辅助整理问题和证据，不能代替专业判断。用户应独立核实事实与来源。
